
# LinkVault

A responsive bookmark manager built using React and Tailwind CSS.

## Features

- Add, edit, and delete bookmarks
- Organize bookmarks into collections
- Add and filter bookmarks using tags
- Search bookmarks instantly
- Light and dark mode
- Persistent browser storage with LocalStorage
- Responsive interface

## Technologies

- React.js
- Vite
- Tailwind CSS
- JavaScript
- Lucide React
- LocalStorage

## Installation

1. Clone this repository.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown in your terminal.

## Storage

Bookmarks are stored locally in the user's browser.
No backend or account registration is required.
